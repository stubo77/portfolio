Dev CLI Toolkit

A composable CLI framework for scaffolding, linting, and releasing internal services — reducing onboarding time from days to minutes.

Timeline 6 weeks
Role Lead Engineer
Stack TypeScript, Node.js
Status Internal tool

Problem

Each new service required engineers to manually copy boilerplate, configure linting, set up CI, and wire release pipelines. This took 1–2 days and was prone to subtle inconsistencies across repos.

Solution

I designed a plugin-based CLI where each command is a self-contained module. The framework handles argument parsing, config discovery, and output formatting, while plugins implement domain-specific logic.

  • dev new — scaffolds a new service from templates
  • dev lint — runs unified linting across language boundaries
  • dev release — bumps versions, generates changelogs, tags, and ships

Impact

After rollout, new service onboarding dropped from ~2 days to under 10 minutes. The toolkit is now used by the entire engineering org across 80+ repos.
